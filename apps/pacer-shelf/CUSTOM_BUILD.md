# Codex Pacer Shelf · 刘海暂存柜定制版

本目录基于 [Codex Pacer](https://github.com/RyanZhangNTU/codex-pacer) 3.1.1 修改，并依照原项目 MIT License 公开源码。

定制内容包括本地暂存抽屉、文件拖入拖出、每页八项分页、剪贴板导入、框选截图、自动收纳新截图、独立应用身份及菜单栏入口。功能规格、验收场景和本机验证记录位于 `docs/local-shelf/`。

构建：

```bash
bash scripts/local/build-shelf.sh
```

当前分享版面向 Apple Silicon 与 macOS 14+，使用本地临时签名，未经过 Apple Developer ID 签名或公证。使用者的账号、会话和暂存内容不在本仓库或发行包中。
