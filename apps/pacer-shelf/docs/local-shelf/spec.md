# 刘海暂存柜：本地实现规格

用户已确认：沿用 Pacer 深色扁平界面，硬件刘海包含于面板顶部；文件卡片正向对齐，无倾斜；暂存区4列×2行，每页最多8项，超出分页；可直接拖入拖出；重启保留。

## 完整流程

1. 收起态悬停/点击刘海展开。文件拖到刘海时展开并提供接收反馈。
2. 从访达拖文件/文件夹、从网页拖图片/链接，或点击添加文件/从剪贴板添加。
3. 异步复制到本应用管理的本地暂存目录，原文件不移动。复制成功才提交清单；失败显示错误且可重试。批量导入维持输入顺序，同名项目独立保存。
4. 显示缩略图/文件图标及文件名；每页8个，页码/前后页按钮可用，删除末页项目后页码自动收敛。
5. 整张卡片均可原生拖出，向目标提供实际文件URL；拖出复制，取消或目标不支持不丢条目。点选可在访达显示；移出只处理暂存副本。
6. 退出后条目清单原子落盘，重新打开恢复；原始文件已移走仍可拖出；损坏清单保留并报告错误。

## 首版范围与默认

- 保留真实任务/额度来源，不用模拟数值替代正式模式。
- 暂存支持文件、文件夹、文字、链接、图片；剪贴板通过明确点击或面板内Cmd+V添加，首版不持续读取整个剪贴板历史。
- 新截图自动接入监听已有Tendedero目录及系统截图保存目录，只收新截图，不回收历史图片；有可见开关，不改系统截图路径。
- 新增框选截图按钮：隐藏刘海面板→系统框选→保存副本→自动回到暂存，取消截图不新增条目。
- 拖放不能激活应用或切换Space；拖文件接近刘海时提前展开，拖拽期间保持展开；已固定面板不因点击访达抓文件而关闭。
- 原生macOS SwiftUI/AppKit拖放；没有新增后端或上传。
- 紧凑面板目标宽度440pt，受硬件刘海和原有状态条最小宽度约束；卡片固定4列，2行不倾斜。
- 本地定制版本独立应用身份与暂存目录，官方版保留；禁用定制版官方自动升级，防止功能被上游版本覆盖。仅本地开发构建，不冒充官方签名/公证发布。

## 完成定义

构建通过、相关自动化测试通过；实际应用界面检查2×4卡片与分页、文件导入、访达拖出、重启保留、错误提示。未实际执行的交互必须单独记录，不以源码或编译代替验收。

## 明确收起入口（后续修正）

任务栏右侧提供带“收起”文字的按钮；点击即取消固定并收起，鼠标未离开时不因悬停立即重开。鼠标离开后再次移入可正常展开，拖文件靠近仍可展开。应用正常启动先显示收起态。

## 朋友版启动可见性与独立性

- 暂存柜使用独立单实例锁及唤醒通知，官方 Pacer 正在运行时不会静默退出；重复打开同一暂存柜只唤起原实例。
- 常驻菜单栏储物箱图标，菜单提供打开、收起、设置及退出。首次启动主动展开一次；后续启动恢复紧凑模式。
- 支持 --verify-package 只读检查包内资源及依赖，不读取账户资料。测试时移开临时构建目录并从新路径解包验证；空配置不依赖本机登录或暂存内容。
