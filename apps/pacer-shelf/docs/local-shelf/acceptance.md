# 验收场景

| 场景 | 操作 | 预期 |
|---|---|---|
| 空状态 | 展开新柜 | 空状态提供拖入、添加文件、剪贴板入口 |
| 文件正常路径 | 拖入文件，随后拖到访达 | 柜中显示；访达得到完整副本，原件与柜条目不变 |
| 文件夹 | 导入含嵌套目录的文件夹 | 保持内部结构，可拖出完整目录 |
| 剪贴板 | 点击添加文字/链接/图片 | 生成可拖出的本地文件，不自动采集其他历史 |
| 分页边界 | 分别导入8、9、17个 | 1、2、3页，任何页最多8张，前后切换不丢条目 |
| 同名与顺序 | 批量添加同名不同路径项目 | 独立保存，显示顺序与输入一致 |
| 重启与源文件 | 导入后移走源文件并重启 | 已保存条目恢复且导出内容一致 |
| 拖出取消 | 拖至不支持的目标后取消 | 项目仍在原页 |
| 移出 | 删除末页最后一项 | 仅管理副本移废纸篓，页码回退合法页 |
| 失败 | 缺失源/不可读源/损坏清单 | 明确错误，已有清单不被清空覆盖 |
| 收起态拖入 | 拖到刘海边翼 | 展开；持续拖放时不自动收起 |
| 截图 | 开启接入后新截图 | 新图进入柜；不扫描导入历史；关闭后停止 |

| 跨应用拖入 | 固定展开后到访达抓文件、拖近刘海 | 保持展开，不抢焦点或切换Space，松手复制 |
| 内置截图 | 点击框选截图，完成/取消 | 完成自动入柜，取消不产生空文件，面板回到当前空间 |

实际执行结果见 [verification.md](verification.md)；未执行的场景不算通过。

手动收起：固定展开→点击“收起”→立即变为紧凑栏；继续悬停不重开；移开再移入正常展开；文件内容保留。正常重启先显示紧凑栏。

朋友版：原版锁被持有时暂存柜仍能取得自己的锁；首次空配置启动出现抽屉与菜单栏入口；收起后可通过菜单再展开；原始构建资源目录不可用时包内中英文及辅助程序检查通过。
